# Agent Note: 会话列表默认展开与持久化折叠（Web）

Status: implemented

[English](2026-09-14-sessions-expand-by-default-persisted-fold.md) | 中文

## 问题

分组会话列表默认呈折叠状态：每个打开的 Workspace 至多显示其前五个非空白 Session（外加临时的新会话行），必须点击"展开其余 N 个会话"才能看到其余部分。该展开状态是 `SessionTree` 内的 React 局部状态，在每次卸载和页面重载时被丢弃，因此任何 Workspace 内 Session 超过五条的用户每次访问都要重新点击该链接——这是一笔折叠状态并未偿还的重复开销。用户的折叠/展开选择没有任何持久化通道，尽管浏览器既有的视图 store 已经持久化了分组方式、排序、归档可见性与分组展开状态。

## 决定

**反转默认值：打开的 Workspace 分组显示其完整会话列表，溢出控件成为真正的折叠开关，且该选择持久化在浏览器既有的 Workspace 视图 store 中。**

- Store：入口声明的视图 store 新增 `sessionFolding: Record<string, boolean>` —— `true` 是显式折叠到五行配额；缺失的键（或 `false`）是展开，即新的默认值。极性与 `groupExpansion`（缺失 = 关闭）刻意相反，因为本特性反转了默认值；该记录存储的是对新默认的*例外*。新的 `setSessionFolded` 动作写入该键，`retainAccountKeys` 在 Workspace 消失时连同另外两个记录一起将其剪掉，因此被删除的 Workspace 不会留下失效的折叠。
- 持久化键：`dsh.workspace.view.v6` → `v7`。引擎以原始 JSON 整体 `setState` 重新水合，所以缺少新记录的 v6 载荷会把 `sessionFolding` 重新水合为 `undefined`，并在动作写入时崩溃；沿用 `showArchived` 升键的先例，旧键被丢弃而非误读。
- 组件：`SessionTree` 失去其临时 `expandedSessionGroups` 状态与 `toggled` 辅助函数；展开判定为 `sessionFolding[group.key] !== true`。溢出控件的门槛不变（分组超过配额时始终渲染），点击把先前的显示状态写入为新折叠值：`true` 折叠，`false` 记录显式展开。分组标题的开关只翻转分组展开状态；折叠与其正交，因此以折叠状态关闭的分组重新打开时仍是折叠的。搜索揭示效果只在折叠存在时才解除（写入 `setSessionFolded(group, false)`）：选中的结果若在折叠配额之外，则解除用户自己的折叠（并持久化该解除）；若在配额之内，或列表本就展开，则记录保持不动。拖拽锚点读取同一位。
- 无需改动 locale：既有的 `sessions.expand` / `sessions.collapse` 键（"展开其余 N 个会话" / "收起"）已能标注新开关的两个方向。

## 考虑的替代方案

**持久化当前的本地展开列表，保持折叠默认值。** 修好了重复点击，却没修好其动因——默认值本身：Session 超过五条的多数 Workspace 每次重载都强制一次点击，而保留旧默认值延续了那个几乎没人主动选择的折叠状态。

**在视图选项菜单里放一个全局"始终显示全部会话"开关。** 去掉了点击，但没去掉抱怨的主体（默认值），且把逐组配额在常见场景下变成死重；逐组折叠对超大 Workspace 仍然有用。

**彻底去掉控件（始终展开）。** 最简单，但五行配额的存在是为了让超大 Workspace 的列表在窄侧边栏里保持可控；保留反向操作保留了这一逃生通道，同时不改变默认值。

## 影响

- Session 无需点击即可见；想要紧凑列表的用户可以折叠它，且该选择从此在重挂载与重载后保留，位置就是已经保存分组方式、排序、归档可见性与分组展开的同一浏览器持久化 store。
- 持久化键升级是一次性客户端重新水合：已存储的视图偏好一次性重置为默认值，其中用户编辑过的会话手动排列是唯一被丢弃而非误读的值。
- 搜索揭示若其行位于用户折叠配额之外，会静默解除（并持久化）该折叠；若在配额之内，则折叠保持不变，因此搜索不会重塑用户未要求更改的列表。
- 新会话 web-e2e 金标从五行加"展开其余 1 个会话"按钮变为全部六行加"收起"；该场景现在还固定了折叠在页面重载后的保留。

## 测试

重写的 `workspace-browser.client.spec.tsx` 固定了默认展开投影、经控件折叠与展开（记录进 store）、折叠在分组关闭再打开后的保留、持久化折叠下空白行不计入配额、持久化折叠下的拖拽锚点、被删除 Workspace 折叠的剪除，以及全部三条揭示路径（配额内的折叠保留、配额外的折叠解除并持久化、已展开列表不受影响）。web e2e 车道固定了新的金标、折叠/展开与重载后的保留；`workspace-management.e2e.ts` 读取升级后的 v7 键，滚动条场景不再点击遍历展开其余链路。包 README（英文与中文）重述了新默认值及其持久化。
