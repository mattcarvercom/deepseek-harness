# Agent Note: 单行深度求索 pill

Status: implemented

[English](2026-09-15-single-line-deep-diving-pill.md) | 中文

## 问题

运行中回合的 pill 长出了超出单行占位的多行。该分组是一个 flex 列：闪烁的 `Deep diving...` 标签与其带门槛的计时、其下方的阶段副标题（压缩、重试、子代理、工具、后台任务或助手流阶段）、再下方的操作行（取消，加条件性的取消并重试、查看日志、终止子代理）。一个等待在途后台任务的回合——一条短的阶段标签加一个常驻控制——最多占到三行对话高度。

## 决定

[ChatView.tsx](../../../../packages/client/ui-chat/src/client/chat/ChatView.tsx) 的 `TurnStatus` 现在把 pill 渲染为单行 flex 行：闪烁标签、带门槛的主计时、locale 拥有的间隔点分隔符、阶段副标题、操作集合。

- 分隔符是聊天 locale 字典里新增的 `chat.pill.separator` 文案（` · `）；标点间距属于本地化决策，所以归字典所有。它是 `aria-hidden`，用 caption token 着色。
- 副标题保留其逐分支的本地化文案与不带门槛的计时，并在共享 caption 样式上加 `font-style: italic`，让它在同一行里读作从属于标签的次级文本。`role="status"` 实时区域仍留在分组上，副标题的出现与变化仍会被播报；两个计时保持 `aria-hidden`。
- 每个操作都是特性本地的圆形仅图标控制：22px 圆形按钮承载 14px 的设计系统字形，可访问名经由 `aria-label` 取各自的既有本地化文案——取消用加粗 fill 关闭图标（`IconCloseFill14`）、取消并重试用环形箭头（`IconRefreshOutline16`）、子代理分支上的查看日志用文档加笔字形（`IconListPenOutline16`）、已锁定本地子代理的终止子代理用实心停止方块（`IconStopFill16`）。ui-primitives 目录没有仅图标的 `Button` 变体，其指南指明特性包是真正专用控件的合适归属；每个字形都是设计系统为对应动作自备的，图标无需标签即可指明其动词。

## 考虑过的替代方案

**把条件性操作保留为带文字标签的按钮。** 本改动的第一稿把取消并重试、查看日志、终止子代理保留为圆角取消之后的 outline 文字按钮。文字一眼可读，但三个词加宽了行，且图标形式毫无损失：每个字形都是设计系统为该动作自备的，可访问名对键盘与屏幕阅读器用户仍是完整的本地化文案。

**用 ui-primitives 的 `Button` 做取消。** 目录的各变体都带标签和可选前置图标，没有一个在小圆形目标里渲染小字形。为一个使用点扩宽共享原语，颠倒了它的提升规则。

**outline 关闭字形，或文本字形。** 12px 的 outline 变体在圆形按钮里读起来像细的文本字形；设计系统加粗的 fill 关闭图标是同一个 X，其笔画粗细在该尺寸下站得住。

**不用分隔符，或用更重的符号。** 裸空格与标签的省略号边界含糊，破折号或竖线读起来像数据定界符。间隔点是最轻的无歧义停顿，且归字典所有给 locale 留了调整余地。

**保留副标题单独一行但把它缩小。** 本改动要移除的垂直占用原样保留。

## 后果

活动回合从最多三行变成一行，整个操作集合都是图标：每个操作的可访问名是既有的本地化文案，指针、键盘、屏幕阅读器路径在名称与接线上都未变。pill 的可见文本变化，因此包含运行中 pill 的 Web golden 输出全部重录；每个 diff 只有 pill 行。没有会话事件、协议或契约变化：阶段派生、Location 数据通道、inject 面均未改动。

## 测试

`chat-view` spec 断言各阶段分支的单行格式、分隔符、每个操作按钮仅图标（无文本内容）、以及经可访问名的取消、取消并重试、查看日志、终止子代理点击；`aria-hidden` 计数断言包含分隔符而不含字形。重录的 Web golden 携带新行。`verify-client-ui-i18n` 通过新增分隔符文案，note 格式与翻译配对门禁通过本笔记。
